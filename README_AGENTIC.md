# The Stable — Agentic Engineering Starter Pack

This pack is intended to be copied into the repository **before implementation** and used from Cursor Plan Mode.

Start here:
1. `AGENTS.md`
2. `planning/ATRD.md`
3. `planning/PLAN.md`
4. `planning/ARCHITECTURE.md`
5. `planning/FEATURE_SCOPE.md`
6. `planning/PERMISSIONS.md`
7. `planning/TESTING.md`
8. `planning/AGENT_WORKSTREAMS.md`
9. `prompts/CURSOR_MASTER_PLAN_PROMPT.md`

The V1 design system is approved. Use `planning/DESIGN_SYSTEM.md` as the implementation contract and `design/stable-v1-final.png` as the visual reference.

The pack configures:
- repository-level and scoped `AGENTS.md`;
- Cursor project rules;
- custom Cursor subagents;
- repeatable Cursor skills;
- isolated-worktree setup;
- architecture decision records;
- milestone and quality gates.

This pack does not contain secrets or production deployment commands.
