## Shared-file rule

A file with more than one interested agent still has **one merge owner**.

Before parallel work the Integrator declares:
- files frozen;
- files single-writer;
- files each worktree may create/edit.

No agent may "help" by editing another agent's owned file during concurrent execution.

## Generated files

Generated artefacts are regenerated by the owner of the source:
- DB types -> Supabase/Data agent.
- API client artefacts -> contract/API owner.
- lockfile -> Integrator/Platform during dependency integration.

Agents must not hand-edit generated files unless the generator explicitly requires it.
