# Definition of Ready / Definition of Done

## Ready
- story states actor/value;
- acceptance scenarios approved;
- scope and non-scope defined;
- capability identified;
- tenant boundary identified;
- data source ownership identified;
- contract known;
- schema impact known;
- notification impact known;
- offline impact known;
- design state available if visual;
- test plan listed;
- dependencies complete.

## Done
- acceptance scenarios pass;
- tests added simultaneously;
- coverage gate passes;
- RLS allow/deny passes where relevant;
- validation passes client + authoritative boundary;
- loading/empty/error states implemented;
- offline state implemented where relevant;
- accessibility checked;
- logs/analytics safe;
- docs updated;
- migration safe/tested;
- build/type/lint pass;
- QA independent review complete;
- security review when trust boundary changed;
- no Critical/High open;
- no disguised TODO.
